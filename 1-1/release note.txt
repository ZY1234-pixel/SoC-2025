DocFlow v0.5.0 Release Notes
============================
Release Date: 2026-04-23

Overview
--------
DocFlow 是一套文档版面还原与渲染系统，支持将扫描件/图片通过 OCR → 版面检测 → 分栏检测
→ 样式推断 → DOCX 渲染的全流程管线，还原可编辑的 Word 文档。

本次 v0.5.0 重点改进了多列布局还原、页面适配防溢页、以及渲染策略的可解释性。

Key Features
------------
1. 多列布局检测改进
   - 排除 TABLE 块对列检测聚类的干扰
   - 支持不规则列宽的自动检测（宽度差异比 ≥ 1.45）
   - 跨列区块（figure、table 等）的版面表格渲染

2. 页面适配与防溢页
   - 基于内容高度预算的 fit_scale 全局缩放估算
   - 分级修正策略：先局部（段后间距/间隙/字号）后全局
   - 两遍/三遍渲染验证 + 字号下限保护（8.5 → 7.0 → 6.5pt）
   - 坐标映射器基于页边距自适应缩放

3. 渲染计划系统
   - render_plan.json 输出，说明每个样本的渲染策略
   - 三种策略：single_col（单栏）、multi_col_table（布局表格）、native_columns（Word 原生分栏）
   - 策略选择基于跨列存在性、列宽规则性、版面复杂度

4. 样式推断
   - 基于内容区块的字体大小、行距中位数推断
   - 页面级别样式的自动提取与回写

5. 报纸/杂志等短横版页面适配
   - 页边距下限 24pt（低于 700pt 高度的页面）
   - 上下边距动态钳位，避免内容密集

Bug Fixes
---------
- 修复表格行在分页处被截断的问题（cantSplit 支持）
- 修复 TABLE 块作为 zone 分隔符导致的区域过度分裂
- 修复 caption 嵌套去重逻辑
- 修复报纸版面还原中大量空白的问题

Known Limitations
-----------------
- 极度复杂的混合版面（如报纸中多张跨列图 + 不规则分栏）可能仍需手动调整
- 数学公式渲染依赖图片回退，LaTeX 渲染需额外配置
